# Circe Bot (Minimal - Node.js)

A lightweight Discord bot built with **Circe** and **Node.js 22+**.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   ```bash
   cp .env.example .env
   ```

3. Run in development mode:
   ```bash
   npm run dev
   ```

## Production

Verify and start:
```bash
npm run build
npm run start
```
