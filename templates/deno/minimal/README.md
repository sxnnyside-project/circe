# Circe Bot (Minimal - Deno)

A minimalist Discord bot built on [Circe](https://github.com/sxnnyside-project/circe) and Deno.

## Getting Started

1. Copy `.env.example` to `.env` and fill in your credentials:
   ```bash
   cp .env.example .env
   ```

2. Run in development mode (no installation step required):
   ```bash
   deno task dev
   ```

## Production

Run your bot in production:
```bash
deno task start
```
