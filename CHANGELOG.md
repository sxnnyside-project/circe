# Changelog

All notable changes to **Circe** are documented here.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)

## [Unreleased]

### Added

- Support for slash commands, guards, events, and dynamic module loading.
- Structured logging with custom levels and AsyncLocalStorage-based correlation context.
- Graceful shutdown state machine lifecycle handlers.
- Testing utilities harness (`circe/testing`).

## [0.0.0] — 2026-08-20

### Added

- Initial MLP (Minimal Lovable Product) implementation for ecosystem bot integration.
